# 🧩 미로찾기 (Maze Game)

팩맨 스타일의 단일 HTML 미로찾기 게임입니다. 외부 라이브러리 없이 `index.html` 하나로 동작합니다.

## 실행

`index.html`을 브라우저에서 열면 바로 플레이할 수 있습니다.

## 기능

- 랜덤 미로 생성 (재귀적 백트래킹, 항상 출구 존재)
- 방향키 / WASD 이동 — 꾹 누르면 연속 이동, 모바일용 화면 버튼 포함
- 난이도 4단계 (11×11 ~ 35×35)
- 길 위의 과자를 먹으며 진행, 진행 방향으로 입을 뻐끔거리는 캐릭터
- 타이머 / 이동 횟수 / 먹은 과자 수 표시, 탈출 시 결과 팝업
